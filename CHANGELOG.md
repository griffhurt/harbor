# Changelog

Release notes for each version. A version's section becomes its GitHub release notes, which
Harbor links to when it offers an update, so write entries for people using the app.

## 1.1.0

Harbor now keeps itself up to date.

- **Automatic updates:** Harbor checks for new versions and can install them for you. Turn
  checking on or off in Harbor › Settings, or choose Harbor › Check for Updates….
- **Help:** Harbor › Help › Harbor Help (⌘?) opens the usage guide.
- **About:** the About window links to the project on GitHub.

1.0.0 can't update itself, so install 1.1.0 once by hand. Updates after that are automatic.

## 1.0.0

The first release of Harbor: folders of apps in the macOS Dock.

- **Folders in the Dock**, alongside your pinned apps, with custom colors, SF Symbols and a
  folder or tile shape.
- **Four popover styles:** Grid, Compact Grid, List and Fan.
- **Add apps** from a searchable list or by dragging them in from Finder.
